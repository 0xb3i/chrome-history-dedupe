# 弹窗视觉方向探索 · 第 01 轮

用户任务：按快捷键打开弹窗，输入关键词，快速认出并打开目标页面。主动作：选中一行 → 回车打开。
设备约束：Chrome 扩展弹窗，宽 580px（Chrome 弹窗上限 800×600），浅色。
风格已定：用户指定 Raycast / macOS 浅色风。上一版被否：装饰堆叠、假毛玻璃、颜色发浑、中文字号过小、日期层级被压平。

## 标杆与取舍（共用）

品类：启动器 / 系统级搜索面板。标杆：Raycast 剪贴板历史（refs/raycast-launcher2/page.png，看图拆）。

拆到的要素：
1. 搜索框无边框，占满顶栏，光标即主角；筛选只有一个右侧下拉（All Types），不铺一排控件。
2. 列表行 40px，左 16–20px 图标，单行标题，不放第二行元信息。
3. 选中行是实心浅灰圆角块（8px），不是蓝色高亮，不加描边。
4. 分组标题 "Today" 是小号次级色文字，没有色块、没有分隔线。
5. 底部 40px 操作栏：左边当前命令名和图标，右边“主操作 ↵ | Actions ⌘K”，键帽是浅底小方块。
6. 细节进右侧详情面板（Information：Application / Content Type / Copied），列表本身保持干净。
7. 下拉菜单自带搜索框，选中项灰底，无勾选。

留：无边框搜索、实心灰选中、底部操作栏、少控件。换：Raycast 是深色加红色光晕，我们是浅色、不加光晕；中文标题需要 14px 而不是 13px。

## 方向

- **A 聚光灯单列**：最贴近 Raycast 浅色。一列，元信息放进行右侧附属区，筛选收进搜索框右侧一个下拉，排序和“仅已命名”进 ⌘K 菜单。色彩只有灰阶，命中词用 macOS 查找黄。
- **B 列表 + 详情**：照搬 Raycast 剪贴板历史的骨架。左列只放标题，右侧详情放来源、访问次数、时间、同页链接。颜色从选中网页的图标取，在详情顶部做一块淡色底。需要 720px 宽弹窗。
- **C 原生列表视图**：像 Finder / 邮件的列表视图。统一工具栏 + 圆角灰底搜索框 + 时间分段控件，表头列、斑马纹行、系统蓝实心选中。信息最密，最“原生 App”。

## 第 01 轮选择

用户选 A 聚光灯单列，并要求换一个更好看的图标。

### 落地到 popup.html（v1.11.0）

- 只改弹窗，样式全部挂在 `.popup-body` 下；完整历史页不变。
- 搜索行：无边框 18px 搜索框 + 时间下拉 + 显示选项按钮（⌘K / Ctrl+K）。仅已命名、排序、主题进面板。
- 结果行：40px 单行。网站图标放在行首列（复用来源按钮里的图标，缺图时用来源色字母块），来源域名紧跟标题且先于标题收缩；状态标签与时间在右；悬停或聚焦时换成改名、固定按钮。访问次数改为时间的悬停提示，并保留在可访问名称里。
- 用户反馈多行标题“挤在一起很局促”：标题一律单行省略，曾用名和区分用的地址仍在第二行。
- 用户反馈改名弹窗没跟上：改为 440px 面板，标题 + 地址、单个 36px 输入框、底部操作栏「还原原名｜取消 esc｜保存 ↵」。
- 底部操作栏：完整历史入口；右侧主按键随焦点切换 ↓ 选择 / ↵ 打开。
- 动效：显示选项面板 140ms 缩放淡入，改名面板 160ms，开关 160ms；减少动态效果时全部直接到位。

### 图标

三选一后（icon/shots/page.png）选「叠页 + 时钟」：一摞重复页合成一张、上面是历史时钟，对应“去重的历史”。16/32px 单独画了简化版（icon-small.svg），8 倍放大检查过像素（icon/shots-zoom/page.png）。

### 第二轮调整（用户反馈）

- 移除完整历史页与 `chrome://history` 接管；备份、恢复、快捷键移到 options.html，⌘K 面板加入口。
- 修改来源名称进 ⌘K 面板，作用于当前选中行。
- 曾用名保留搜索，行内不再显示，改为标题悬停提示；去掉「跨时间保留」标注。
- 来源名称完整显示（上限 168px），标题先省略；时间列统一右对齐，链接数量放在时间左侧。
- 按最近访问排序时恢复示例页里的时间分段（已固定 / 今天 / 昨天 / 本周 / 月份）。
- 底部栏去掉图标，左侧改为结果数量。

### 第三轮调整（交互逻辑）

- 用户指出：筛选按钮应只管搜索；⌘K 应是“针对当前 tab 的操作”；同名链接的路径对用户没有信息量。
- 筛选与排序面板只留仅显示已命名、排序和「设置…」。主题移到设置页（src/theme.js 共用）。
- ⌘K / 右键打开当前行的操作面板（打开、复制链接、重命名、固定、同名的其他链接、只看此来源、修改来源名称）；行内悬停按钮全部移除。
- 同名链接在列表里合并为一行，打开访问最多的链接；其余放进 ⌘K 子列表，以访问时间区分，F2 可单独重命名使其独立成行。
- 高亮：浅黄底 + 深黄下划线（highlight/shots/page.png 比较了 5 种）。
